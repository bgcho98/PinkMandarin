데이터 삭제

내가 보스 몬스터다 - 퍼즐 · 이용자 데이터 삭제 안내

내가 보스 몬스터다 - 퍼즐이 서버에 저장한 이용자 데이터를 지우는 방법입니다.

이메일로 삭제 요청하기

  • 이메일: help@pinkmandarin.com
  • 제목: [내가 보스 몬스터다 - 퍼즐] 데이터 삭제 요청
  • 본문: 마왕 이름, 군단, 현재 마왕 레벨을 적어 주세요. 홈 화면 스크린샷을 함께 보내 주시면 본인 확인이 빨라집니다.

요청을 받은 날부터 10일 안에 삭제하고, 결과를 이메일로 알려 드립니다.

페이스북에서 게임 연결 끊기

페이스북 설정 → 앱 및 웹사이트 → 인스턴트 게임에서 이 게임을 지우면 페이스북과 게임의 연결이 끊깁니다. 이 방법만으로는 서버의 게임 데이터가 지워지지 않으니, 위 이메일로 삭제를 요청해 주세요.

삭제되는 데이터

  • 로그인 계정 (게임 전용 플레이어 ID)
  • 서버에 저장된 게임 진행 데이터 전부 (마왕 이름, 골드, 군단, 몬스터, 마왕, 레벨, 방어 기록)
  • 랭킹 기록
  • 초대 기록 (초대한 기록과 초대받은 기록)

지운 뒤에는 계정 식별자와 삭제 시각만 남깁니다. 같은 기기에서 게임을 다시 열면 기기에 남은 옛 기록은 버리고 처음부터 시작합니다.

주의: 삭제한 데이터는 복구할 수 없습니다.

Data Deletion

I Am The Boss Monster: Puzzle · User Data Deletion Instructions

How to delete the user data that I Am The Boss Monster: Puzzle stores on its server.

Request Deletion by Email

  • Email: help@pinkmandarin.com
  • Subject: [I Am The Boss Monster: Puzzle] Data deletion request
  • Body: Include your Demon Lord name, legion, and current Demon Lord level. A screenshot of your home screen helps us verify you faster.

We delete your data within 10 days of receiving the request and confirm by email.

Remove the Game on Facebook

Removing the Game in Facebook Settings → Apps and Websites → Instant Games disconnects it from your Facebook account. This alone does not delete your game data on our server, so please also request deletion by email above.

Data Deleted

  • Sign-in account (game-scoped player ID)
  • All game progress data stored on the server (Demon Lord name, gold, legion, monsters, Demon Lords, level, defense records)
  • Ranking records
  • Invite records (both invites you sent and the invite you joined from)

After deletion, we keep only the account identifier and deletion time. If you open the Game again on the same device, the old records left on the device are discarded and you start fresh.

Warning: Deleted data cannot be recovered.
